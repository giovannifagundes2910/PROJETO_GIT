O que é Git e GITHUB?

Git

O Git é um sistema de controle de versões que permite acompanhar as alterações realizadas nos arquivos de um projetos.

Com ele, podemos registrar alterações, recuperar versões anteriores e trabalhar em equipe.

GitHub

O GitHub é uma plataforma online que permite armazenar e compartilhar repositórios Git.

Por meio dele, podemos compartilhar projetos, colaborar com outros desenvolvedores e visualizar o histórico de alterações.

Comandos para praticar

Clique em um comando para abrir sua explicação. No teclado, use Tab e Enter.

1. git init - iniciar um repositório

Execute na pasta do projeto para começar a controlar suas versões.

git init
2. git status - conferir as alterações

Mostra quais arquivos foram modificados e quais estão preparados para o próximo commit.

git status
3. git add - preparar os arquivos

Prepara as alterações dos dois arquivos para o próximo commit. Ainda não cria uma versões.

git add index.html styles.css
4. commit - registrar uma versão

Resgistra as alterações preparadas. Escreva uma mensagem que explique o que você fez.

git commit -m "Adiciona area de estudos"
5. git log - consultar o histórico

Exibe os commits de forma resumida, com um registro por linha.

git log --oneline
6. git push - enviar para o GitHub

Envia os commits para o repositório remoto. Este exemplo exige um remoto chamado origin, uma branch chamada main e autenticação configurados com o professor.

git push -u origin main
